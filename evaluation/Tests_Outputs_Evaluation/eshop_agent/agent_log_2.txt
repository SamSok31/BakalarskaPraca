Use Case: Manage E-Shop Backend System
Primary Actor: User (Administrator/Customer)
Goal: Manage users, products, carts, reservations, and orders in an e-shop backend system while ensuring correct handling of current available stock.

---

**System Responsibilities:**
- Manage user accounts, including creation and deletion.
- Maintain product catalog with attributes (name, price, stock).
- Handle cart operations, including adding/removing products and managing reservations.
- Process checkout to create orders with atomicity guarantees.
- Update order statuses following strict transition rules.
- Maintain current available stock, ensuring reserved quantities are deducted and returned appropriately.
- Provide access to system state (users, products, stock, carts, orders).
- Enforce consistency across all operations, ignoring invalid inputs or non-existing entities.

---

**Preconditions:**
- The e-shop backend system is initialized and operational.
- No prior state is required for user/product creation, but operations on existing entities assume their presence.

---

**Postconditions:**
- Users, products, carts, reservations, and orders are created, modified, or deleted as requested.
- Current available stock reflects all reservations, returns, and cancellations.
- Orders are created with unique sequential IDs and snapshotted prices.
- System state remains consistent after any operation.

---

**Main Success Scenario:**

### 1. Create User
1. Actor requests to create a user with a unique ID.
2. System validates the ID is not a duplicate.
3. System creates the user and an empty cart.
4. System confirms user creation.

### 2. Delete User
1. Actor requests to delete a user by ID.
2. System validates the user exists.
3. System removes the user’s cart and cancels all their reservations:
   - For each reserved product:
     - If the product exists in stock, the reserved quantity is returned to current available stock.
     - If the product no longer exists, the reservation is removed without stock adjustment.
4. System deletes the user while preserving their orders.
5. System confirms user deletion.

### 3. Add/Update Product
1. Actor requests to add a product with name, price, and stock.
2. System checks if a product with the same name exists:
   - If yes, updates its price and increases current available stock by the provided quantity.
   - If no, creates a new product with the provided attributes.
3. System confirms product addition/update.

### 4. Delete Product
1. Actor requests to delete a product by name.
2. System validates the product exists.
3. System removes the product from current available stock.
4. System preserves existing reservations and orders for the product.
5. System confirms product deletion.

### 5. Modify Cart
1. Actor requests to add/remove a product to/from their cart with a specified quantity.
2. System validates the user and product exist.
3. **Add Product to Cart:**
   - System checks if the requested quantity is available in current stock.
   - If available, deducts the quantity from current stock and creates/updates the reservation.
   - If unavailable or quantity is zero, ignores the request.
4. **Remove Product from Cart:**
   - System checks if the removal quantity is valid (≤ reserved quantity).
   - If valid, returns the quantity to current stock (if product exists) or removes the reservation (if product no longer exists).
   - If invalid, ignores the request.
5. System confirms cart modification.

### 6. Checkout
1. Actor requests to checkout their cart.
2. System validates the cart is not empty.
3. System checks all reserved products still exist in the stock system.
4. System calculates the total price using current product prices.
5. System creates a new order with:
   - Unique sequential ID (e.g., "SK00001").
   - Status "pending".
   - Snapshotted product prices.
6. System clears the cart and corresponding reservations.
7. System confirms checkout success.

### 7. Update Order Status
1. Actor requests to update an order’s status to a valid target state.
2. System validates the order exists and the transition is allowed:
   - Follows sequence: pending → processing → completed → shipped → delivered.
   - Allows transition to "cancelled" from any state.
   - Ignores transitions from "cancelled" or to invalid states.
3. **If transitioning to "cancelled":**
   - For each product in the order:
     - If the product exists in stock, increases current available stock by the ordered quantity.
     - If the product no longer exists, recreates it with the snapshotted price and ordered quantity.
4. System updates the order status.
5. System confirms status update.

---

**Extensions:**

### 1. Create User
1a. Duplicate user ID → System ignores the request.
1b. Invalid user ID → System ignores the request.

### 2. Delete User
2a. User does not exist → System ignores the request.

### 3. Add/Update Product
3a. Product name is empty or invalid → System ignores the request.
3b. Price or stock is negative → System ignores the request.

### 4. Delete Product
4a. Product does not exist → System ignores the request.

### 5. Modify Cart
5a. User or product does not exist → System ignores the request.
5b. Add request with zero or negative quantity → System ignores the request.
5c. Add request exceeds available stock → System ignores the request.
5d. Remove request exceeds reserved quantity → System ignores the request.

### 6. Checkout
6a. Cart is empty → System ignores the request.
6b. Any reserved product no longer exists → System fails checkout and applies no changes.
6c. System error during checkout → System fails checkout and applies no changes (atomicity).

### 7. Update Order Status
7a. Order does not exist → System ignores the request.
7b. Invalid status transition → System ignores the request.

---

**Special Requirements:**
- The system must be implemented in Python using object-oriented design.
- All operations must be atomic where specified (e.g., checkout).
- Order IDs must be globally unique, sequential, and never reused.
- System must ignore operations on non-existing entities or with invalid inputs.
- Current available stock must always reflect reserved quantities accurately.
- Status transitions must adhere to the defined sequence.

- The system must be implemented in Python using object-oriented design.
- All operations must be atomic where specified (e.g., checkout).
- Order IDs must be globally unique, sequential, and never reused.
- System must ignore operations on non-existing entities or with invalid inputs.
- Current available stock must always reflect reserved quantities accurately, and reserved quantities must not be available to other users.
- Status transitions must adhere to the defined sequence, with "cancelled" allowed from any status.
- Existing reservations and orders must remain unchanged when products are deleted.
- Existing orders must remain unaffected when users are deleted.

def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
    # Validate user exists
    if user_id not in self.users:
        return False

    # Validate product exists
    if product_name not in self.products:
        return False

    # Validate quantity is positive for addition
    if quantity <= 0:
        return False

    user = self.users[user_id]
    product = self.products[product_name]

    # Check if we're adding to cart
    if quantity > 0:
        # Check stock availability
        if product_name not in self.stock or self.stock[product_name] < quantity:
            return False

        # Update stock
        self.stock[product_name] -= quantity

        # Update cart
        if product_name in user.cart:
            user.cart[product_name] += quantity
        else:
            user.cart[product_name] = quantity

    # Check if we're removing from cart
    elif quantity < 0:
        abs_quantity = abs(quantity)

        # Check if product is in cart and quantity is sufficient
        if product_name not in user.cart or user.cart[product_name] < abs_quantity:
            return False

        # Update cart
        user.cart[product_name] -= abs_quantity
        if user.cart[product_name] == 0:
            del user.cart[product_name]

        # Return to stock if product exists
        if product_name in self.stock:
            self.stock[product_name] += abs_quantity
        # If product doesn't exist, we don't need to do anything else

    return True

def checkout(self, user_id: str) -> tuple[bool, str | None]:
    # Step 1: Validate user exists and cart is not empty
    if user_id not in self.users or not self.users[user_id].cart:
        return False, None

    user = self.users[user_id]
    cart = user.cart
    total_price = 0.0
    order_items = {}

    # Step 2: Validate all products in cart have sufficient stock
    for product_name, quantity in cart.items():
        if product_name not in self.products or product_name not in self.stock:
            return False, None

        if self.stock[product_name] < quantity:
            return False, None

        # Calculate total price and prepare order items
        product = self.products[product_name]
        total_price += product.price * quantity
        order_items[product_name] = {
            'price': product.price,
            'quantity': quantity
        }

    # Step 3: Generate order ID and create order
    order_id = f"SK{self.next_order_id:05d}"
    order = Order(
        order_id=order_id,
        user_id=user_id,
        items=order_items,
        total_price=total_price,
        status='pending'
    )

    # Step 4: Update system state atomically
    self.orders[order_id] = order
    self.next_order_id += 1

    # Clear cart and reservations
    user.cart.clear()

    return True, order_id

def update_order_status(self, order_id: str, target_status: str) -> bool:
    # Validate order exists
    if order_id not in self.orders:
        return False

    order = self.orders[order_id]
    current_status = order.status

    # Validate status transition
    valid_transitions = {
        'pending': ['processing', 'cancelled'],
        'processing': ['completed', 'cancelled'],
        'completed': ['shipped', 'cancelled'],
        'shipped': ['delivered', 'cancelled'],
        'delivered': ['cancelled']
    }

    if target_status not in valid_transitions.get(current_status, []):
        return False

    # Handle cancellation
    if target_status == 'cancelled':
        for product_name, quantity in order.items.items():
            if product_name in self.products:
                # Product exists, increase stock
                self.stock[product_name] += quantity
            else:
                # Product doesn't exist, recreate it
                price = order.prices[product_name]
                self.products[product_name] = Product(name=product_name, price=price)
                self.stock[product_name] = quantity

    # Update order status
    order.status = target_status
    return True

    def __init__(self, order_id: str, status: str, products: dict[str, dict]):

class EShopBackend:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.stock = {}

    def create_user(self, user_id: str) -> bool:
        if not user_id or user_id in self.users:
            return False

        new_user = User(user_id)
        self.users[user_id] = new_user
        return True

    def delete_user(self, user_id: str) -> bool:
        if user_id not in self.users:
            return False

        user = self.users[user_id]
        for product_name, quantity in list(user.cart.items()):
            if product_name in self.products and product_name in self.stock:
                self.stock[product_name] += quantity
            del user.cart[product_name]

        del self.users[user_id]
        return True

    def add_or_update_product(self, name: str, price: float, stock: int) -> bool:
        if not name.strip() or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name].price = price
            self.stock[name] += stock
        else:
            new_product = Product(name, price)
            self.products[name] = new_product
            self.stock[name] = stock

        return True

    def delete_product(self, name: str) -> bool:
        if name not in self.products:
            return False

        del self.products[name]
        del self.stock[name]
        return True

    def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
        # Validate user exists
        if user_id not in self.users:
            return False

        # Validate product exists
        if product_name not in self.products:
            return False

        user = self.users[user_id]
        product = self.products[product_name]

        # Check if we're adding to cart
        if quantity > 0:
            # Check stock availability
            if product_name not in self.stock or self.stock[product_name] < quantity:
                return False

            # Update stock
            self.stock[product_name] -= quantity

            # Update cart
            if product_name in user.cart:
                user.cart[product_name] += quantity
            else:
                user.cart[product_name] = quantity

        # Check if we're removing from cart
        elif quantity < 0:
            abs_quantity = abs(quantity)

            # Check if product is in cart and quantity is sufficient
            if product_name not in user.cart or user.cart[product_name] < abs_quantity:
                return False

            # Update cart
            user.cart[product_name] -= abs_quantity
            if user.cart[product_name] == 0:
                del user.cart[product_name]

            # Return to stock if product exists in stock
            if product_name in self.stock:
                self.stock[product_name] += abs_quantity

        return True

    def checkout(self, user_id: str) -> tuple[bool, str | None]:
        # Step 1: Validate user exists and cart is not empty
        if user_id not in self.users or not self.users[user_id].cart:
            return False, None

        user = self.users[user_id]
        cart = user.cart
        total_price = 0.0
        order_items = {}

        # Step 2: Validate all products in cart have sufficient stock
        for product_name, quantity in cart.items():
            if product_name not in self.products or product_name not in self.stock:
                return False, None

            # Verify reserved quantity matches current stock
            if self.stock[product_name] < quantity:
                return False, None

            # Calculate total price and prepare order items
            product = self.products[product_name]
            total_price += product.price * quantity
            order_items[product_name] = {
                'price': product.price,
                'quantity': quantity
            }

        # Step 3: Generate order ID and create order
        order_id = f"SK{self.next_order_id:05d}"
        order = Order(
            order_id=order_id,
            products=order_items,
            status='pending'
        )

        # Step 4: Update system state atomically
        try:
            # First update stock
            for product_name, quantity in cart.items():
                self.stock[product_name] -= quantity

            # Then create order
            self.orders[order_id] = order
            self.next_order_id += 1

            # Finally clear cart
            user.cart.clear()

            return True, order_id
        except:
            # Rollback all changes if any error occurs
            for product_name, quantity in cart.items():
                if product_name in self.stock:
                    self.stock[product_name] += quantity
            return False, None

    def update_order_status(self, order_id: str, target_status: str) -> bool:
        # Validate order exists
        if order_id not in self.orders:
            return False

        order = self.orders[order_id]
        current_status = order.status

        # Validate status transition
        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if target_status not in valid_transitions.get(current_status, []):
            return False

        # Validate target status is a valid status string
        valid_statuses = ['pending', 'processing', 'completed', 'shipped', 'delivered', 'cancelled']
        if target_status not in valid_statuses:
            return False

        # Handle cancellation
        if target_status == 'cancelled':
            for product_name, product_data in order.products.items():
                if product_name in self.products:
                    # Product exists, increase stock
                    self.stock[product_name] += product_data['quantity']
                else:
                    # Product doesn't exist, recreate it with snapshotted price and quantity
                    self.products[product_name] = Product(name=product_name, price=product_data['price'])
                    self.stock[product_name] = product_data['quantity']

        # Update order status
        order.status = target_status
        return True

    def get_system_state(self) -> dict:
        """Provides access to the current system state."""
        state = {
            'users': {user_id: {'cart': user.cart} for user_id, user in self.users.items()},
            'products': {name: {'price': product.price, 'stock': self.stock[name]}
                        for name, product in self.products.items()},
            'stock': self.stock.copy(),
            'orders': {order_id: {'status': order.status}
                      for order_id, order in self.orders.items()}
        }
        return state

class User:
    def __init__(self, user_id: str) -> None:
        self.user_id = user_id
        self.cart = {}

class Product:
    def __init__(self, name: str, price: float):
        self.name = name
        self.price = price

class Order:
    def __init__(self, order_id: str, status: str, products: dict[str, dict]):
        self.order_id = order_id
        self.status = status
        self.products = products

class EShopBackend:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.stock = {}

    def create_user(self, user_id: str) -> bool:
        if not user_id or user_id in self.users:
            return False

        new_user = User(user_id)
        self.users[user_id] = new_user
        return True

    def delete_user(self, user_id: str) -> bool:
        if user_id not in self.users:
            return False

        user = self.users[user_id]
        for product_name, quantity in list(user.cart.items()):
            if product_name in self.products and product_name in self.stock:
                self.stock[product_name] += quantity
            del user.cart[product_name]

        del self.users[user_id]
        return True

    def add_or_update_product(self, name: str, price: float, stock: int) -> bool:
        if not name.strip() or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name].price = price
            self.stock[name] += stock
        else:
            new_product = Product(name, price)
            self.products[name] = new_product
            self.stock[name] = stock

        return True

    def delete_product(self, name: str) -> bool:
        if name not in self.products:
            return False

        del self.products[name]
        del self.stock[name]
        return True

    def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
        # Validate user exists
        if user_id not in self.users:
            return False

        # Validate product exists
        if product_name not in self.products:
            return False

        # Validate quantity is non-zero
        if quantity == 0:
            return False

        user = self.users[user_id]
        product = self.products[product_name]

        # Check if we're adding to cart
        if quantity > 0:
            # Check stock availability
            if product_name not in self.stock or self.stock[product_name] < quantity:
                return False

            # Update stock
            self.stock[product_name] -= quantity

            # Update cart
            if product_name in user.cart:
                user.cart[product_name] += quantity
            else:
                user.cart[product_name] = quantity

        # Check if we're removing from cart
        elif quantity < 0:
            abs_quantity = abs(quantity)

            # Check if product is in cart and quantity is sufficient
            if product_name not in user.cart or user.cart[product_name] < abs_quantity:
                return False

            # Update cart
            user.cart[product_name] -= abs_quantity
            if user.cart[product_name] == 0:
                del user.cart[product_name]

            # Return to stock if product exists in stock
            if product_name in self.stock:
                self.stock[product_name] += abs_quantity

        return True

    def checkout(self, user_id: str) -> tuple[bool, str | None]:
        # Step 1: Validate user exists and cart is not empty
        if user_id not in self.users or not self.users[user_id].cart:
            return False, None

        user = self.users[user_id]
        cart = user.cart
        total_price = 0.0
        order_items = {}

        # Step 2: Validate all products in cart have sufficient stock
        for product_name, quantity in cart.items():
            if product_name not in self.products or product_name not in self.stock:
                return False, None

            # Verify reserved quantity matches current stock
            if self.stock[product_name] < quantity:
                return False, None

            # Calculate total price and prepare order items
            product = self.products[product_name]
            total_price += product.price * quantity
            order_items[product_name] = {
                'price': product.price,
                'quantity': quantity
            }

        # Step 3: Generate order ID and create order
        order_id = f"SK{self.next_order_id:05d}"
        order = Order(
            order_id=order_id,
            products=order_items,
            status='pending'
        )

        # Step 4: Update system state atomically
        try:
            # First update stock
            for product_name, quantity in cart.items():
                self.stock[product_name] -= quantity

            # Then create order
            self.orders[order_id] = order
            self.next_order_id += 1

            # Finally clear cart
            user.cart.clear()

            return True, order_id
        except:
            # Rollback all changes if any error occurs
            for product_name, quantity in cart.items():
                if product_name in self.stock:
                    self.stock[product_name] += quantity
            return False, None

    def update_order_status(self, order_id: str, target_status: str) -> bool:
        # Validate order exists
        if order_id not in self.orders:
            return False

        order = self.orders[order_id]
        current_status = order.status

        # Validate status transition
        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if target_status not in valid_transitions.get(current_status, []):
            return False

        # Validate target status is a valid status string
        valid_statuses = ['pending', 'processing', 'completed', 'shipped', 'delivered', 'cancelled']
        if target_status not in valid_statuses:
            return False

        # Handle cancellation
        if target_status == 'cancelled':
            for product_name, product_data in order.products.items():
                if product_name in self.products:
                    # Product exists, increase stock
                    self.stock[product_name] += product_data['quantity']
                else:
                    # Product doesn't exist, recreate it with snapshotted price and quantity
                    self.products[product_name] = Product(name=product_name, price=product_data['price'])
                    self.stock[product_name] = product_data['quantity']

        # Update order status
        order.status = target_status
        return True

    def get_system_state(self) -> dict:
        """Provides access to the current system state."""
        state = {
            'users': {user_id: {'cart': user.cart} for user_id, user in self.users.items()},
            'products': {name: {'price': product.price, 'stock': self.stock[name]}
                        for name, product in self.products.items()},
            'stock': self.stock.copy(),
            'orders': {order_id: {'status': order.status}
                      for order_id, order in self.orders.items()}
        }
        return state

The generated e-shop backend does not satisfy the specification due to inconsistent handling of stock and reservations.

Key issues:

1. **Incorrect stock handling**

* Stock is deducted multiple times (during reservation and again during checkout).
* This leads to lower-than-expected available stock and breaks consistency across operations.

2. **Invalid checkout logic**

* Checkout sometimes fails even when it should succeed.
* The system appears to validate availability using already reduced stock, causing false “insufficient stock” conditions.
* Checkout is not reliably atomic (cart is not always cleared, order not always created).

3. **Reservation inconsistency**

* Reserved quantities are not correctly reflected in available stock.
* The relationship between carts, reservations, and stock is inconsistent across operations.

4. **Incorrect stock restoration**

* Cancelling an order does not correctly restore stock.
* Deleting a user does not properly release reserved quantities back to stock.

Summary:
The system violates the core invariant between available stock and reserved quantities. Stock should be reduced exactly once during reservation and remain consistent across all operations (cart updates, checkout, cancellation, and user deletion).

def update_order_status(self, order_id: str, target_status: str) -> bool:
    # Validate order exists
    if order_id not in self.orders:
        return False

    order = self.orders[order_id]
    current_status = order.status

    # Validate status transition
    valid_transitions = {
        'pending': ['processing', 'cancelled'],
        'processing': ['completed', 'cancelled'],
        'completed': ['shipped', 'cancelled'],
        'shipped': ['delivered', 'cancelled'],
        'delivered': ['cancelled']
    }

    if target_status not in valid_transitions.get(current_status, []):
        return False

    # Handle cancellation
    if target_status == 'cancelled':
        for product_name, quantity in order.items.items():
            if product_name in self.products:
                # Product exists, increase stock
                self.stock[product_name] += quantity
            else:
                # Product doesn't exist, recreate it
                price = order.prices[product_name]
                self.products[product_name] = Product(name=product_name, price=price)
                self.stock[product_name] = quantity

    # Update order status
    order.status = target_status
    return True

class EShopBackend:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.stock = {}

    def create_user(self, user_id: str) -> bool:
        if not user_id or user_id in self.users:
            return False

        new_user = User(user_id)
        self.users[user_id] = new_user
        return True

    def delete_user(self, user_id: str) -> bool:
        if user_id not in self.users:
            return False

        user = self.users[user_id]
        for product_name, quantity in list(user.cart.items()):
            if product_name in self.products and product_name in self.stock:
                self.stock[product_name] += quantity
            del user.cart[product_name]

        del self.users[user_id]
        return True

    def add_or_update_product(self, name: str, price: float, stock: int) -> bool:
        if not name.strip() or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name].price = price
            self.stock[name] += stock
        else:
            new_product = Product(name, price)
            self.products[name] = new_product
            self.stock[name] = stock

        return True

    def delete_product(self, name: str) -> bool:
        if name not in self.products:
            return False

        del self.products[name]
        del self.stock[name]
        return True

    def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
        if user_id not in self.users or product_name not in self.products:
            return False

        if quantity == 0:
            return False

        user = self.users[user_id]
        product = self.products[product_name]

        if quantity > 0:
            if product_name not in self.stock or self.stock[product_name] < quantity:
                return False

            self.stock[product_name] -= quantity
            if product_name in user.cart:
                user.cart[product_name] += quantity
            else:
                user.cart[product_name] = quantity
        else:
            abs_quantity = abs(quantity)
            if product_name not in user.cart or user.cart[product_name] < abs_quantity:
                return False

            user.cart[product_name] -= abs_quantity
            if user.cart[product_name] == 0:
                del user.cart[product_name]

            if product_name in self.stock:
                self.stock[product_name] += abs_quantity

        return True

    def checkout(self, user_id: str) -> tuple[bool, str | None]:
        if user_id not in self.users or not self.users[user_id].cart:
            return False, None

        user = self.users[user_id]
        cart = user.cart
        order_items = {}

        for product_name, quantity in cart.items():
            if product_name not in self.products or product_name not in self.stock:
                return False, None

            if self.stock[product_name] < quantity:
                return False, None

            product = self.products[product_name]
            order_items[product_name] = {
                'price': product.price,
                'quantity': quantity
            }

        order_id = f"SK{self.next_order_id:05d}"
        order = Order(
            order_id=order_id,
            products=order_items,
            status='pending'
        )

        try:
            for product_name, quantity in cart.items():
                self.stock[product_name] -= quantity

            self.orders[order_id] = order
            self.next_order_id += 1
            user.cart.clear()

            return True, order_id
        except:
            for product_name, quantity in cart.items():
                if product_name in self.stock:
                    self.stock[product_name] += quantity
            return False, None

    def update_order_status(self, order_id: str, target_status: str) -> bool:
        if order_id not in self.orders:
            return False

        order = self.orders[order_id]
        current_status = order.status

        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if target_status not in valid_transitions.get(current_status, []):
            return False

        valid_statuses = ['pending', 'processing', 'completed', 'shipped', 'delivered', 'cancelled']
        if target_status not in valid_statuses:
            return False

        if target_status == 'cancelled':
            for product_name, product_data in order.products.items():
                if product_name in self.products:
                    self.stock[product_name] += product_data['quantity']
                else:
                    self.products[product_name] = Product(name=product_name, price=product_data['price'])
                    self.stock[product_name] = product_data['quantity']

        order.status = target_status
        return True

    def get_system_state(self) -> dict:
        state = {
            'users': {user_id: {'cart': user.cart} for user_id, user in self.users.items()},
            'products': {name: {'price': product.price, 'stock': self.stock[name]}
                        for name, product in self.products.items()},
            'stock': self.stock.copy(),
            'orders': {order_id: {'status': order.status}
                      for order_id, order in self.orders.items()}
        }
        return state

        self.orders = {}
        self.next_order_id = 1
        self.stock = {}

    def create_user(self, user_id: str) -> bool:
        if not user_id or user_id in self.users:
            return False

        new_user = User(user_id)
        self.users[user_id] = new_user
        return True

    def delete_user(self, user_id: str) -> bool:
        if user_id not in self.users:
            return False

        user = self.users[user_id]
        for product_name, quantity in list(user.cart.items()):
            if product_name in self.products and product_name in self.stock:
                self.stock[product_name] += quantity
            if product_name in self.reserved_stock:
                del self.reserved_stock[product_name]
            del user.cart[product_name]

        del self.users[user_id]
        return True

    def add_or_update_product(self, name: str, price: float, stock: int) -> bool:
        if not name.strip() or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name].price = price
            self.stock[name] += stock
        else:
            new_product = Product(name, price)
            self.products[name] = new_product
            self.stock[name] = stock

        return True

    def delete_product(self, name: str) -> bool:
        if name not in self.products:
            return False

        del self.products[name]
        del self.stock[name]
        if name in self.reserved_stock:
            del self.reserved_stock[name]
        return True

    def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
        if user_id not in self.users or product_name not in self.products:
            return False

        if quantity == 0:
            return False

        user = self.users[user_id]
        product = self.products[product_name]

        if quantity > 0:
            if product_name not in self.stock or self.stock[product_name] < quantity:
                return False

            self.stock[product_name] -= quantity
            if product_name in self.reserved_stock:
                self.reserved_stock[product_name] += quantity
            else:
                self.reserved_stock[product_name] = quantity

            if product_name in user.cart:
                user.cart[product_name] += quantity
            else:
                user.cart[product_name] = quantity
        else:
            abs_quantity = abs(quantity)
            if product_name not in user.cart or user.cart[product_name] < abs_quantity:
                return False

            user.cart[product_name] -= abs_quantity
            if user.cart[product_name] == 0:
                del user.cart[product_name]

            if product_name in self.stock:
                self.stock[product_name] += abs_quantity
            if product_name in self.reserved_stock:

        if user_id not in self.users or not self.users[user_id].cart:

            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if target_status not in valid_transitions.get(current_status, []):
            return False

        valid_statuses = ['pending', 'processing', 'completed', 'shipped', 'delivered', 'cancelled']

class User:
    def __init__(self, user_id: str) -> None:
        self.user_id = user_id
        self.cart = {}

class Product:
    def __init__(self, name: str, price: float):
        self.name = name
        self.price = price

class Order:
    def __init__(self, order_id: str, status: str, products: dict[str, dict]):
        self.order_id = order_id
        self.status = status
        self.products = products

class EShopBackend:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.stock = {}
        self.reserved_stock = {}

    def create_user(self, user_id: str) -> bool:
        if not user_id or user_id in self.users:
            return False

        new_user = User(user_id)
        self.users[user_id] = new_user
        return True

    def delete_user(self, user_id: str) -> bool:
        if user_id not in self.users:
            return False

        user = self.users[user_id]
        for product_name, quantity in list(user.cart.items()):
            if product_name in self.products and product_name in self.stock:
                self.stock[product_name] += quantity
            if product_name in self.reserved_stock:
                del self.reserved_stock[product_name]
            del user.cart[product_name]

        del self.users[user_id]
        return True

    def add_or_update_product(self, name: str, price: float, stock: int) -> bool:
        if not name.strip() or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name].price = price
            self.stock[name] += stock
        else:
            new_product = Product(name, price)
            self.products[name] = new_product
            self.stock[name] = stock

        return True

    def delete_product(self, name: str) -> bool:
        if name not in self.products:
            return False

        del self.products[name]
        del self.stock[name]
        if name in self.reserved_stock:
            del self.reserved_stock[name]
        return True

    def modify_cart(self, user_id: str, product_name: str, quantity: int) -> bool:
        if user_id not in self.users or product_name not in self.products:
            return False

        if quantity == 0:
            return False

        user = self.users[user_id]
        product = self.products[product_name]

        if quantity > 0:
            if product_name not in self.stock or self.stock[product_name] < quantity:
                return False

            self.stock[product_name] -= quantity
            if product_name in self.reserved_stock:
                self.reserved_stock[product_name] += quantity
            else:
                self.reserved_stock[product_name] = quantity

            if product_name in user.cart:
                user.cart[product_name] += quantity
            else:
                user.cart[product_name] = quantity
        else:
            abs_quantity = abs(quantity)
            if product_name not in user.cart or user.cart[product_name] < abs_quantity:
                return False

            user.cart[product_name] -= abs_quantity
            if user.cart[product_name] == 0:
                del user.cart[product_name]

            if product_name in self.stock:
                self.stock[product_name] += abs_quantity
            if product_name in self.reserved_stock:
                self.reserved_stock[product_name] -= abs_quantity
                if self.reserved_stock[product_name] == 0:
                    del self.reserved_stock[product_name]

        return True

    def checkout(self, user_id: str) -> tuple[bool, str | None]:
        if user_id not in self.users or not self.users[user_id].cart:
            return False, None

        user = self.users[user_id]
        cart = user.cart
        order_items = {}

        for product_name, quantity in cart.items():
            if product_name not in self.products or product_name not in self.stock:
                return False, None

            if self.stock[product_name] < quantity:
                return False, None

            product = self.products[product_name]
            order_items[product_name] = {
                'price': product.price,
                'quantity': quantity
            }

        order_id = f"SK{self.next_order_id:05d}"
        order = Order(
            order_id=order_id,
            products=order_items,
            status='pending'
        )

        try:
            for product_name, quantity in cart.items():
                if product_name in self.reserved_stock:
                    del self.reserved_stock[product_name]

            self.orders[order_id] = order
            self.next_order_id += 1
            user.cart.clear()

            return True, order_id
        except:
            for product_name, quantity in cart.items():
                if product_name in self.stock:
                    self.stock[product_name] += quantity
                if product_name in self.reserved_stock:
                    self.reserved_stock[product_name] += quantity
            return False, None

    def update_order_status(self, order_id: str, target_status: str) -> bool:
        if order_id not in self.orders:
            return False

        order = self.orders[order_id]
        current_status = order.status

        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if target_status not in valid_transitions.get(current_status, []):
            return False

        valid_statuses = ['pending', 'processing', 'completed', 'shipped', 'delivered', 'cancelled']
        if target_status not in valid_statuses:
            return False

        if target_status == 'cancelled':
            for product_name, product_data in order.products.items():
                if product_name in self.products:
                    self.stock[product_name] += product_data['quantity']
                else:
                    self.products[product_name] = Product(name=product_name, price=product_data['price'])
                    self.stock[product_name] = product_data['quantity']

        order.status = target_status
        return True

    def get_system_state(self) -> dict:
        state = {
            'users': {user_id: {'cart': user.cart} for user_id, user in self.users.items()},
            'products': {name: {'price': product.price, 'stock': self.stock[name]}
                        for name, product in self.products.items()},
            'stock': self.stock.copy(),
            'reserved_stock': self.reserved_stock.copy(),
            'orders': {order_id: {'status': order.status}
                      for order_id, order in self.orders.items()}
        }
        return state
