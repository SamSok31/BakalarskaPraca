Use Case: Manage E-Shop Backend System
Primary Actor: Administrator / User
Goal: Manage users, products, carts, reservations, and orders in an e-shop backend system while ensuring correct stock handling.

System Responsibilities:
- Manage user accounts, including creation and deletion.
- Maintain product inventory with attributes (name, price, stock).
- Handle cart operations, including adding/removing products and managing reservations.
- Process checkout operations to finalize orders.
- Manage order lifecycle and status transitions.
- Ensure atomicity and consistency in all operations.
- Maintain current system state (users, products, stock, carts, reservations, orders).
- Enforce business rules for stock availability, reservations, and order processing.

---

**Use Case: Create User**
Primary Actor: Administrator
Goal: Create a new user in the system.

Preconditions:
- The system is operational.

Postconditions:
- A new user with a unique ID exists in the system.
- An empty cart is associated with the new user.

Main Success Scenario:
1. Administrator requests to create a new user with a specified ID.
2. System validates the user ID is unique.
3. System creates the new user.
4. System initializes an empty cart for the user.

Extensions:
2a. User ID already exists → System ignores the request and notifies the administrator.

---

**Use Case: Delete User**
Primary Actor: Administrator
Goal: Delete an existing user from the system.

Preconditions:
- The user exists in the system.

Postconditions:
- The user no longer exists in the system.
- The user’s cart and reservations are removed.
- Reserved product quantities are returned to available stock if the product still exists.
- The user’s orders remain unaffected.

Main Success Scenario:
1. Administrator requests to delete a user by ID.
2. System removes the user’s cart and cancels all associated reservations.
3. For each reservation:
   a. If the product exists, the reserved quantity is returned to available stock.
   b. If the product no longer exists, the reservation is removed without stock adjustment.
4. System deletes the user.

Extensions:
1a. User does not exist → System ignores the request.

---

**Use Case: Add Product**
Primary Actor: Administrator
Goal: Add a new product or update an existing product’s stock and price.

Preconditions:
- The system is operational.

Postconditions:
- A new product is added to the system, or an existing product’s stock and price are updated.
- Available stock reflects the updated quantity.

Main Success Scenario:
1. Administrator requests to add a product with attributes (name, price, stock).
2. System checks if a product with the same name already exists.
3. If the product exists:
   a. System increases the product’s stock by the specified quantity.
   b. System updates the product’s price.
4. If the product does not exist:
   a. System creates a new product with the specified attributes.
5. System updates the available stock.

Extensions:
1a. Stock or price is negative → System ignores the request.
2a. Product name is empty → System ignores the request.

**Use Case: Delete Product**
Primary Actor: Administrator
Goal: Remove a product from the stock system.

Preconditions:
- The product exists in the system.

Postconditions:
- The product is removed from the stock system.
- Reservations and orders involving the product remain unchanged.

Main Success Scenario:
1. Administrator requests to delete a product by name.
2. System removes the product from the stock system.
3. System updates the available stock to exclude the deleted product.

Extensions:
1a. Product does not exist → System ignores the request.

**Use Case: Modify Cart**
Primary Actor: User
Goal: Add or remove products from the user’s cart.

Preconditions:
- The user exists in the system.
- The cart exists for the user.

Postconditions:
- The cart reflects the updated product quantities.
- Reservations are created or updated for added products.
- Reserved quantities are deducted from available stock.
- Removed quantities are returned to available stock if the product still exists.

Main Success Scenario (Add Product):
1. User requests to add a product with a specified quantity to their cart.
2. System checks if the product exists and the requested quantity is available.
3. If the product is already in the cart:
   a. System increases the reserved quantity for the product.
4. If the product is not in the cart:
   a. System creates a new reservation for the product.
5. System deducts the reserved quantity from available stock.

Main Success Scenario (Remove Product):
1. User requests to remove a product with a specified quantity from their cart.
2. System checks if the product exists in the cart and the requested quantity is valid.
3. System reduces the reserved quantity for the product.
4. If the product still exists in stock, the removed quantity is returned to available stock.
5. If the product no longer exists, the reservation is removed without stock adjustment.

Extensions:
1a. Product does not exist or quantity is zero/negative → System ignores the request.
2a. Requested quantity exceeds available stock (add) → System ignores the request.
2a. Requested quantity exceeds reserved quantity (remove) → System ignores the request.

**Use Case: Perform Checkout**
Primary Actor: User
Goal: Finalize the user’s cart as an order.

Preconditions:
- The user exists in the system.
- The cart is not empty.

Postconditions:
- A new order with status "pending" is created.
- The order includes a snapshot of product prices at checkout.
- The cart and reservations are cleared.
- Order ID is generated in the format "SK00001" (sequential and unique).

Main Success Scenario:
1. User requests to checkout their cart.
2. System validates all reserved products still exist in the stock system.
3. System calculates the total price using current product prices.
4. System creates a new order with status "pending" and stores the price snapshot.
5. System generates a unique order ID in the format "SK0000X".
6. System clears the user’s cart and reservations.

Extensions:
1a. Cart is empty → System ignores the request.
2a. Any reserved product no longer exists → System fails the checkout and reverts all changes.
5a. Checkout fails for any reason → System ensures no changes are applied (atomicity).

---

**Use Case: Update Order Status**
Primary Actor: Administrator
Goal: Update the status of an existing order.

Preconditions:
- The order exists in the system.

Postconditions:
- The order’s status is updated according to the allowed transitions.
- If the order is cancelled, stock is adjusted or products are recreated as needed.

Main Success Scenario:
1. Administrator requests to update an order’s status to a new valid status.
2. System validates the status transition is allowed.
3. If the new status is "cancelled":
   a. For each product in the order:
      i. If the product exists, the ordered quantity is returned to available stock.
      ii. If the product no longer exists, it is recreated with the price stored in the order.
4. System updates the order status.

Extensions:
1a. Order does not exist → System ignores the request.
2a. Status transition is invalid → System ignores the request.
3a. "cancelled" is a terminal state → Further status changes are ignored.

---

Postconditions:
- The current state of users, products, stock, carts, reservations, and orders is provided.

   b. List of current products (name, price, stock).
   c. Current available stock.
   d. Carts and reservations of all users.
   e. Orders and their statuses.

None.

def perform_checkout(self, user_id):
    # Step 1: Validate user exists and cart is not empty
    if user_id not in self.users or not self.users[user_id]['cart']:
        return None

    cart = self.users[user_id]['cart']
    total_price = 0.0
    order_products = {}

    # Step 2: Validate all reserved products still exist and calculate total price
    for product_name, quantity in cart.items():
        if product_name not in self.products:
            # Revert all changes and notify user
            for p, q in cart.items():
                if p in self.products:
                    self.products[p]['stock'] += q
            if user_id in self.reservations:
                del self.reservations[user_id]
            return None

        total_price += self.products[product_name]['price'] * quantity
        order_products[product_name] = {
            'quantity': quantity,
            'price': self.products[product_name]['price']
        }

    # Step 3: Generate unique order ID atomically
    order_id = f"SK{self.next_order_id:05d}"
    self.next_order_id += 1

    # Step 4: Create order

        'status': 'pending',
        'products': order_products,
        'total_price': total_price
    }

    # Step 5: Clear cart and reservations

    if user_id in self.reservations:
        del self.reservations[user_id]

import threading

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.reservations = {}
        self.lock = threading.Lock()

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return

        if name in self.products:
            self.products[name]['stock'] += stock
            self.products[name]['price'] = price
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def create_user(self, user_id):
        if user_id in self.users:
            print(f"Warning: User ID {user_id} already exists. Request ignored.")
            return

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }

    def delete_user(self, user_id):
        if user_id not in self.users:
            print(f"Warning: User ID {user_id} does not exist. Request ignored.")
            return

        # Handle reservations and stock adjustments
        if user_id in self.reservations:
            for product_name, quantity in list(self.reservations[user_id].items()):
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
            # Remove the user's reservations entry
            del self.reservations[user_id]

        # Clear cart contents
        if 'cart' in self.users[user_id]:
            self.users[user_id]['cart'].clear()

        # Delete the user
        del self.users[user_id]

    def delete_product(self, name):
        if name in self.products:
            del self.products[name]

    def modify_cart(self, user_id, product_name, quantity, action):
        # Validate user exists and quantity is positive
        if user_id not in self.users or quantity <= 0:
            return

        # Handle add action
        if action == 'add':
            # Check product exists and has sufficient stock
            if product_name not in self.products or quantity > self.products[product_name]['stock']:
                return

            # Update cart and reservations
            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            # Update reservations
            if user_id not in self.reservations:
                self.reservations[user_id] = {}
            if product_name in self.reservations[user_id]:
                self.reservations[user_id][product_name] += quantity
            else:
                self.reservations[user_id][product_name] = quantity

            # Deduct from available stock
            self.products[product_name]['stock'] -= quantity

        # Handle remove action
        elif action == 'remove':
            # Check product exists in cart and has sufficient reserved quantity
            if (product_name not in self.users[user_id]['cart'] or
                quantity > self.users[user_id]['cart'][product_name]):
                return

            # Update cart
            self.users[user_id]['cart'][product_name] -= quantity
            if self.users[user_id]['cart'][product_name] == 0:
                del self.users[user_id]['cart'][product_name]

            # Update reservations
            if user_id in self.reservations and product_name in self.reservations[user_id]:
                self.reservations[user_id][product_name] -= quantity
                if self.reservations[user_id][product_name] == 0:
                    del self.reservations[user_id][product_name]
                    if not self.reservations[user_id]:
                        del self.reservations[user_id]

            # Return stock to available if product exists
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity

    def perform_checkout(self, user_id):
        # Step 1: Validate user exists and cart is not empty
        if user_id not in self.users or not self.users[user_id]['cart']:
            print(f"Warning: User ID {user_id} does not exist or cart is empty. Checkout failed.")
            return None

        cart = self.users[user_id]['cart']
        total_price = 0.0
        order_products = {}

        # Step 2: Validate all reserved products still exist and calculate total price
        for product_name, quantity in cart.items():
            if product_name not in self.products:
                # Revert all changes and notify user
                for p, q in cart.items():
                    if p in self.products:
                        self.products[p]['stock'] += q
                if user_id in self.reservations:
                    del self.reservations[user_id]
                print(f"Warning: Product {product_name} no longer exists. Checkout failed.")
                return None

            total_price += self.products[product_name]['price'] * quantity
            order_products[product_name] = {
                'quantity': quantity,
                'price': self.products[product_name]['price']
            }

        # Step 3: Generate unique order ID atomically
        with self.lock:
            order_id = f"SK{self.next_order_id:05d}"
            self.next_order_id += 1

        # Store original state for potential rollback
        original_stock = {p: self.products[p]['stock'] for p in cart if p in self.products}
        original_reservations = self.reservations.get(user_id, {}).copy()

        try:
            # Step 4: Create order
            self.orders[order_id] = {
                'status': 'pending',
                'products': order_products,
                'total_price': total_price
            }

            # Step 5: Clear cart and reservations
            self.users[user_id]['cart'].clear()
            if user_id in self.reservations:
                del self.reservations[user_id]

            return order_id
        except:
            # Revert all changes if order creation fails
            for p, q in cart.items():
                if p in self.products:
                    self.products[p]['stock'] = original_stock.get(p, self.products[p]['stock'])
            if user_id in self.reservations:
                self.reservations[user_id] = original_reservations
            print(f"Warning: Checkout failed for user {user_id}. All changes reverted.")
            return None

    def update_order_status(self, order_id, new_status):
        # Validate order exists and status transition is allowed
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        # Check if current status is 'cancelled' (terminal state)
        if current_status == 'cancelled':
            return

        # Validate status transition
        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        # Handle cancellation
        if new_status == 'cancelled':
            for product_name, product_data in order['products'].items():
                quantity = product_data['quantity']

                if product_name in self.products:
                    # Return stock to available stock
                    self.products[product_name]['stock'] += quantity
                else:
                    # Recreate product with price from order snapshot
                    self.products[product_name] = {
                        'price': product_data['price'],
                        'stock': quantity
                    }

        # Update order status
        order['status'] = new_status

    def get_system_state(self):
        # Compile users state including carts and reservations
        users_state = {
            user_id: {
                'cart': self.users[user_id]['cart'],
                'reservations': self.reservations.get(user_id, {})
            }
            for user_id in self.users
        }

        # Compile products state including available stock (stock not reserved in any cart)
        products_state = {
            product_name: {
                'price': self.products[product_name]['price'],
                'available_stock': self.products[product_name]['stock']
            }
            for product_name in self.products
        }

        # Compile orders state
        orders_state = {
            order_id: {
                'status': self.orders[order_id]['status'],
                'products': self.orders[order_id]['products'],
                'total_price': self.orders[order_id]['total_price']
            }
            for order_id in self.orders
        }

        # Return compiled state
        return {
            'users': users_state,
            'products': products_state,
            'available_stock': {p: d['available_stock'] for p, d in products_state.items()},
            'carts': {u: d['cart'] for u, d in users_state.items()},
            'reservations': {u: d['reservations'] for u, d in users_state.items()},
            'orders': orders_state
        }

   - The system state snapshot reflects the latest data for users, products, carts, reservations, and orders.

### **Main Success Scenario:**

#### **1. Add/Update Product**
1. Administrator requests to add a new product or update an existing product’s stock/price.
2. System validates the product name, price (≥ 0), and stock (≥ 0).
3. System updates the product catalog:
   - If the product exists, increments stock and updates price.
   - If the product is new, adds it to the catalog with the specified stock and price.

#### **2. Create User**
1. Administrator requests to create a new user with a unique ID.
2. System validates that the user ID does not already exist.
3. System creates the user with an empty cart and no reservations.

#### **3. Modify User Cart**
1. User requests to add/remove a product from their cart.
2. System validates:
   - The user exists.
   - The product exists and has sufficient stock (for "add").
   - The product is in the cart and the quantity is valid (for "remove").
3. System updates the cart:
   - For "add": Reserves the product stock and updates the cart.
   - For "remove": Releases the product stock and updates the cart.

#### **4. Perform Checkout**
1. User requests to checkout their cart.
2. System validates:
   - The user exists and the cart is not empty.
   - All products in the cart still exist and are available.
3. System:
   - Calculates the total order price.
   - Generates a unique order ID.
   - Creates an order with status "pending."
   - Clears the user’s cart and releases reservations.
4. System returns the order ID to the user.

#### **5. Update Order Status**
1. Administrator requests to update an order’s status (e.g., "pending" → "processing").
2. System validates:
   - The order exists.
   - The status transition is valid (e.g., "pending" → "processing" is allowed; "pending" → "delivered" is not).
3. System updates the order status.
   - If the new status is "cancelled," restocks all products in the order.

#### **6. Delete User**
1. Administrator requests to delete a user.
2. System validates that the user exists.
3. System:
   - Releases all reserved stock for the user.
   - Clears the user’s cart.
   - Removes the user from the system.

#### **7. Delete Product**
1. Administrator requests to delete a product.
2. System validates that the product exists.
3. System removes the product from the catalog.

#### **8. View System State**
1. Administrator requests the current system state.
2. System compiles and returns:
   - User data (carts, reservations).
   - Product data (prices, available stock).
   - Order data (status, products, total price).

  - System ignores the request.

- If the product does not exist:

import threading

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.reservations = {}
        self.lock = threading.Lock()

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return

        if name in self.products:
            self.products[name]['stock'] += stock
            self.products[name]['price'] = price
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def create_user(self, user_id):
        if user_id in self.users:
            print(f"Warning: User ID {user_id} already exists. Request ignored.")
            print(f"Notification: Administrator notified about duplicate user ID {user_id}.")
            return

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }

    def delete_user(self, user_id):
        if user_id not in self.users:
            print(f"Warning: User ID {user_id} does not exist. Request ignored.")
            return

        # Clear cart contents
        if 'cart' in self.users[user_id]:
            self.users[user_id]['cart'].clear()

        # Handle reservations and stock adjustments
        if user_id in self.reservations:
            for product_name, quantity in list(self.reservations[user_id].items()):
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
            # Remove the user's reservations entry
            del self.reservations[user_id]

        # Delete the user
        del self.users[user_id]

    def delete_product(self, name):
        if name in self.products:
            del self.products[name]

    def modify_cart(self, user_id, product_name, quantity, action):
        # Validate user exists and quantity is positive
        if user_id not in self.users or quantity <= 0:
            return

        # Handle add action
        if action == 'add':
            # Check product exists and has sufficient stock
            if product_name not in self.products or quantity > self.products[product_name]['stock']:
                return

            # Update cart and reservations
            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            # Update reservations
            if user_id not in self.reservations:
                self.reservations[user_id] = {}
            if product_name in self.reservations[user_id]:
                self.reservations[user_id][product_name] += quantity
            else:
                self.reservations[user_id][product_name] = quantity

            # Deduct from available stock
            self.products[product_name]['stock'] -= quantity

        # Handle remove action
        elif action == 'remove':
            # Check product exists in cart and has sufficient reserved quantity
            if (product_name not in self.users[user_id]['cart'] or
                quantity > self.users[user_id]['cart'][product_name]):
                return

            # Check product still exists in stock system
            if product_name not in self.products:
                return

            # Update cart
            self.users[user_id]['cart'][product_name] -= quantity
            if self.users[user_id]['cart'][product_name] == 0:
                del self.users[user_id]['cart'][product_name]

            # Update reservations
            if user_id in self.reservations and product_name in self.reservations[user_id]:
                self.reservations[user_id][product_name] -= quantity
                if self.reservations[user_id][product_name] == 0:
                    del self.reservations[user_id][product_name]
                    if not self.reservations[user_id]:
                        del self.reservations[user_id]

            # Return stock to available if product exists
            self.products[product_name]['stock'] += quantity

    def perform_checkout(self, user_id):
        # Step 1: Validate user exists and cart is not empty
        if user_id not in self.users or not self.users[user_id]['cart']:
            print(f"Warning: User ID {user_id} does not exist or cart is empty. Checkout failed.")
            return None

        cart = self.users[user_id]['cart']
        total_price = 0.0
        order_products = {}

        # Step 2: Validate all reserved products still exist and calculate total price
        for product_name, quantity in cart.items():
            if product_name not in self.products:
                # Revert all changes and notify user
                for p, q in cart.items():
                    if p in self.products:
                        self.products[p]['stock'] += q
                if user_id in self.reservations:
                    del self.reservations[user_id]
                print(f"Warning: Product {product_name} no longer exists. Checkout failed.")
                return None

            total_price += self.products[product_name]['price'] * quantity
            order_products[product_name] = {
                'quantity': quantity,
                'price': self.products[product_name]['price']
            }

        # Step 3: Generate unique order ID atomically
        with self.lock:
            order_id = f"SK{self.next_order_id:05d}"
            self.next_order_id += 1

        # Store original state for potential rollback
        original_stock = {p: self.products[p]['stock'] for p in cart if p in self.products}
        original_reservations = self.reservations.get(user_id, {}).copy()

        try:
            # Step 4: Create order
            self.orders[order_id] = {
                'status': 'pending',
                'products': order_products,
                'total_price': total_price
            }

            # Step 5: Clear cart and reservations
            self.users[user_id]['cart'].clear()
            if user_id in self.reservations:
                del self.reservations[user_id]

            return order_id
        except:
            # Revert all changes if order creation fails
            for p, q in cart.items():
                if p in self.products:
                    self.products[p]['stock'] = original_stock.get(p, self.products[p]['stock'])
            if user_id in self.reservations:
                self.reservations[user_id] = original_reservations
            print(f"Warning: Checkout failed for user {user_id}. All changes reverted.")
            return None

    def update_order_status(self, order_id, new_status):
        # Validate order exists and status transition is allowed
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        # Check if current status is 'cancelled' (terminal state)
        if current_status == 'cancelled':
            return

        # Validate status transition
        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled']
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        # Handle cancellation
        if new_status == 'cancelled':
            for product_name, product_data in order['products'].items():
                quantity = product_data['quantity']

                if product_name in self.products:
                    # Return stock to available stock
                    self.products[product_name]['stock'] += quantity
                else:
                    # Recreate product with price from order snapshot
                    self.products[product_name] = {
                        'price': product_data['price'],
                        'stock': quantity
                    }

        # Update order status
        order['status'] = new_status

    def get_system_state(self):
        # Compile users state including carts and reservations
        users_state = {
            user_id: {
                'cart': self.users[user_id]['cart'],
                'reservations': self.reservations.get(user_id, {})
            }
            for user_id in self.users
        }

        # Compile products state including available stock (stock not reserved in any cart)
        products_state = {
            product_name: {
                'price': self.products[product_name]['price'],
                'available_stock': self.products[product_name]['stock']
            }
            for product_name in self.products
        }

        # Compile orders state
        orders_state = {
            order_id: {
                'status': self.orders[order_id]['status'],
                'products': self.orders[order_id]['products'],
                'total_price': self.orders[order_id]['total_price']
            }
            for order_id in self.orders
        }

        # Return compiled state
        return {
            'users': users_state,
            'products': products_state,
            'available_stock': {p: d['available_stock'] for p, d in products_state.items()},
            'carts': {u: d['cart'] for u, d in users_state.items()},
            'reservations': {u: d['reservations'] for u, d in users_state.items()},
            'orders': orders_state
        }

def test_alternative_flow_product_deletion():

    system.delete_product("phone")
