Use Case: Manage E-Shop Backend System
Primary Actor: User (Administrator/Customer)
Goal: Manage users, products, carts, reservations, and orders in an e-shop backend system while ensuring correct handling of current available stock.

System Responsibilities:
- Manage user accounts, including creation, deletion, and associated carts/reservations.
- Manage product inventory, including addition, deletion, and stock updates.
- Handle cart modifications, including product additions/removals and reservations.
- Process checkout operations to create orders with atomicity guarantees.
- Manage order lifecycle, including status transitions and cancellations.
- Maintain consistency of current available stock across all operations.
- Enforce uniqueness and sequential generation of order IDs.
- Preserve historical data (e.g., order prices) independent of current product state.
- Validate all operations for existence, correctness, and consistency.

Preconditions:
- The e-shop backend system is initialized and operational.
- No prior state is required for user/product creation, but all operations assume valid system state.

Postconditions:
- Users, products, carts, reservations, and orders are in a consistent state.
- Current available stock reflects all successful operations.
- Order IDs are globally unique and sequentially assigned.
- Historical data (e.g., cancelled orders) is preserved as required.

---

### Use Case: Create User
**Primary Actor:** Administrator
**Goal:** Add a new user to the system with a unique ID and an empty cart.

**System Responsibilities:**
- Validate uniqueness of user ID.
- Create an empty cart for the new user.
- Persist the user and associated cart.

**Preconditions:**
- The system is operational.

**Postconditions:**
- A new user with the specified ID exists in the system.
- The user has an empty cart.
- Current available stock remains unchanged.

**Main Success Scenario:**
1. Administrator requests to create a user with a specified ID.
2. System validates that the ID is unique.
3. System creates the user with the ID.
4. System initializes an empty cart for the user.
5. System confirms successful creation.

**Extensions:**
2a. User ID already exists → System ignores the request and notifies the administrator.

---

### Use Case: Delete User
**Primary Actor:** Administrator
**Goal:** Remove a user from the system, including their cart and reservations, while preserving their orders.

**System Responsibilities:**
- Remove the user’s cart and cancel all associated reservations.
- Return reserved quantities to current available stock if the product still exists.
- Preserve the user’s existing orders.

**Preconditions:**
- The user exists in the system.

**Postconditions:**
- The user no longer exists in the system.
- The user’s cart and reservations are removed.
- Current available stock is updated if products still exist.
- The user’s orders remain unchanged.

**Main Success Scenario:**
1. Administrator requests to delete a user with a specified ID.
2. System retrieves the user’s cart and reservations.
3. For each reservation:
   a. If the product exists, return the reserved quantity to current available stock.
   b. If the product no longer exists, remove the reservation without affecting stock.
4. System removes the user’s cart.
5. System deletes the user.
6. System confirms successful deletion.

**Extensions:**
1a. User does not exist → System ignores the request.

---

### Use Case: Add Product
**Primary Actor:** Administrator
**Goal:** Add a new product or update an existing product’s stock and price.

**System Responsibilities:**
- Validate product attributes (name, price, stock).
- If the product exists, update its stock and price.
- If the product does not exist, create it with the specified attributes.

**Preconditions:**
- The system is operational.

**Postconditions:**
- The product exists in the system with the specified name, price, and stock.
- Current available stock reflects the addition or update.

**Main Success Scenario:**
1. Administrator requests to add a product with name, price, and stock.
2. System checks if the product already exists.
3. If the product exists:
   a. System increases the current available stock by the specified quantity.
   b. System updates the product’s price.
4. If the product does not exist:
   a. System creates the product with the specified attributes.
5. System confirms successful addition/update.

**Extensions:**
1a. Product attributes are invalid (e.g., negative price) → System ignores the request.
2a. Product name is empty → System ignores the request.

---

### Use Case: Delete Product
**Primary Actor:** Administrator
**Goal:** Remove a product from the current available stock system while preserving reservations and orders.

**System Responsibilities:**
- Remove the product from current available stock.
- Preserve existing reservations and orders for the product.

**Preconditions:**
- The product exists in the system.

**Postconditions:**
- The product no longer exists in the current available stock system.
- Reservations and orders for the product remain unchanged.

**Main Success Scenario:**
1. Administrator requests to delete a product with a specified name.
2. System removes the product from current available stock.
3. System confirms successful deletion.

**Extensions:**
1a. Product does not exist → System ignores the request.

---

### Use Case: Modify Cart
**Primary Actor:** Customer
**Goal:** Add or remove products from the user’s cart, updating reservations and current available stock.

**System Responsibilities:**
- Validate product existence and available stock.
- Update reservations and current available stock for additions/removals.
- Ignore invalid operations (e.g., zero quantity, insufficient stock).

**Preconditions:**
- The user exists in the system.
- The product exists in the system (for additions).

**Postconditions:**
- The user’s cart reflects the requested modifications.
- Reservations and current available stock are updated accordingly.

**Main Success Scenario (Add Product):**
1. Customer requests to add a product with a specified quantity to their cart.
2. System validates that the product exists and the quantity is positive.
3. System checks if the requested quantity is available in current available stock.
4. If the product is already in the cart:
   a. System increases the reserved quantity by the specified amount.
5. If the product is not in the cart:
   a. System creates a new reservation for the product and quantity.
6. System deducts the quantity from current available stock.
7. System confirms successful addition.

**Main Success Scenario (Remove Product):**
1. Customer requests to remove a product with a specified quantity from their cart.
2. System validates that the product exists in the cart and the quantity is positive.
3. System checks if the requested quantity is ≤ the reserved quantity.
4. System reduces the reserved quantity by the specified amount.
5. If the reserved quantity reaches zero:
   a. System removes the reservation.
6. If the product still exists in the stock system:
   a. System returns the quantity to current available stock.
7. System confirms successful removal.

**Extensions:**
1a. Product does not exist → System ignores the request.
1b. Quantity is zero or negative → System ignores the request.
3a. Requested quantity exceeds available stock (addition) → System ignores the request.
3a. Requested quantity exceeds reserved quantity (removal) → System ignores the request.
5a. Product no longer exists in the stock system → System removes the reservation without affecting stock.

### Use Case: Checkout
**Primary Actor:** Customer
**Goal:** Convert the user’s cart into an order, clearing the cart and reservations.

**System Responsibilities:**
- Validate that the cart is not empty.
- Ensure all reserved products still exist in the stock system.
- Create an order with a unique ID and snapshot of product prices.
- Clear the cart and reservations.
- Enforce atomicity (all-or-nothing).

**Preconditions:**
- The user exists in the system.
- The user’s cart is not empty.

**Postconditions:**
- A new order with status "pending" exists in the system.
- The order ID is globally unique and sequential.
- The user’s cart and reservations are cleared.
- Current available stock remains unchanged (reserved quantities were already deducted).

**Main Success Scenario:**
1. Customer requests to checkout their cart.
2. System validates that the cart is not empty.
3. System checks that all reserved products still exist in the stock system.
4. System calculates the total price using current product prices.
5. System generates a unique order ID in the format "SK00001".
6. System creates an order with the ID, user ID, product snapshots, and status "pending".
7. System clears the user’s cart and reservations.
8. System confirms successful checkout.

**Extensions:**
2a. Cart is empty → System ignores the request.
3a. Any reserved product no longer exists → System ignores the request and notifies the customer.

**Special Requirements:**
- Checkout must be atomic; no partial changes are allowed.
- Order IDs must be globally unique and strictly sequential.

---

### Use Case: Update Order Status
**Primary Actor:** Administrator
**Goal:** Transition an order’s status according to the allowed sequence or cancel it.

**System Responsibilities:**
- Validate the requested status transition.
- Update the order status if valid.
- Handle cancellations by returning stock or recreating products.

**Preconditions:**
- The order exists in the system.

**Postconditions:**
- The order’s status is updated if the transition is valid.
- For cancellations, current available stock is updated or products are recreated.

**Main Success Scenario (Status Transition):**
1. Administrator requests to update an order’s status to a specified value.
2. System validates the requested transition against the allowed sequence.
3. System updates the order status.
4. System confirms successful update.

**Main Success Scenario (Cancellation):**
1. Administrator requests to cancel an order.
2. For each product in the order:
   a. If the product exists in the stock system:
      i. System increases current available stock by the ordered quantity.
   b. If the product no longer exists:
      i. System recreates the product with the price stored in the order.
3. System updates the order status to "cancelled".
4. System confirms successful cancellation.

**Extensions:**
1a. Order does not exist → System ignores the request.
2a. Status transition is invalid → System ignores the request.
2b. Order is already in a terminal state (e.g., "cancelled" or "delivered" with invalid transition) → System ignores the request.

**Special Requirements:**
- Status transitions must follow the sequence: pending → processing → completed → shipped → delivered.
- "cancelled" is a terminal state and can be reached from any status.
- From "delivered", only "cancelled" is allowed.

**Main Success Scenario:**

2. System retrieves the requested data.
3. System returns the data to the actor.

**Extensions:**

def checkout(self, user_id):
    # Check if user exists
    if user_id not in self.users:
        return None

    # Check if cart is empty
    cart = self.users[user_id]['cart']
    if not cart:
        return None

    # Validate all reserved products exist
    for product_name in cart:
        if product_name not in self.products:
            return None

    # Validate reserved quantities match current reservations
    reservations = self.users[user_id]['reservations']
    for product_name, quantity in cart.items():
        if reservations.get(product_name, 0) != quantity:
            return None

    # Calculate total price
    price_snapshot = {}
    total_price = 0.0
    for product_name, quantity in cart.items():
        price = self.products[product_name]['price']
        price_snapshot[product_name] = price
        total_price += price * quantity

    # Generate order ID in a thread-safe manner
    with self.lock:
        order_id = f"SK{self.next_order_id:05d}"
        self.next_order_id += 1

    # Create order
    self.orders[order_id] = {
        'user_id': user_id,
        'products': [{'name': name, 'quantity': qty} for name, qty in cart.items()],
        'status': 'pending',
        'price_snapshot': price_snapshot
    }

    # Clear cart and reservations
    self.users[user_id]['cart'] = {}
    self.users[user_id]['reservations'] = {}

    return order_id

def update_order_status(self, order_id, new_status):
    # Check if the order exists
    if order_id not in self.orders:
        return False

    current_status = self.orders[order_id]['status']

    # If the current status is 'cancelled', ignore the request
    if current_status == 'cancelled':
        return False

    # Validate the status transition
    if new_status not in self.order_status_sequence.get(current_status, []):
        return False

    # Special case: if current status is 'delivered', only allow 'cancelled'
    if current_status == 'delivered' and new_status != 'cancelled':
        return False

    # Handle cancellation
    if new_status == 'cancelled':
        for product_name, quantity in self.orders[order_id]['products']:
            if product_name in self.products:
                # Product exists, increase stock
                self.products[product_name]['stock'] += quantity
            else:
                # Product doesn't exist, recreate it with order's price
                price = self.orders[order_id]['price_snapshot'].get(product_name, 0.0)
                self.products[product_name] = {
                    'price': price,
                    'stock': quantity
                }

    # Update the order status
    self.orders[order_id]['status'] = new_status
    return True

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.order_status_sequence = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }
        self.lock = threading.Lock()

    def create_user(self, user_id):
        if user_id in self.users:
            return False

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }
        return True

    def delete_user(self, user_id):
        if user_id not in self.users:
            return False
        user_data = self.users[user_id]
        reservations = user_data['reservations']
        for product_name, quantity in reservations.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
        del self.users[user_id]
        return True

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

        return True

    def delete_product(self, name):
        if name not in self.products:
            return False

        del self.products[name]
        return True

    def modify_cart(self, user_id, product_name, quantity, action):
        if user_id not in self.users:
            return False

        if action == 'add':
            if quantity <= 0:
                return False

            if product_name not in self.products:
                return False

            if quantity > self.products[product_name]['stock']:
                return False

            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] += quantity
            else:
                self.users[user_id]['reservations'][product_name] = quantity

            self.products[product_name]['stock'] -= quantity
            return True

        elif action == 'remove':
            if product_name not in self.users[user_id]['cart'] or quantity <= 0:
                return False

            if quantity > self.users[user_id]['cart'][product_name]:
                return False

            if product_name not in self.products:
                return False

            self.users[user_id]['cart'][product_name] -= quantity

            if self.users[user_id]['cart'][product_name] == 0:
                del self.users[user_id]['cart'][product_name]

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] -= quantity
                if self.users[user_id]['reservations'][product_name] == 0:
                    del self.users[user_id]['reservations'][product_name]

            self.products[product_name]['stock'] += quantity
            return True

        return False

    def checkout(self, user_id):
        if user_id not in self.users:
            return None

        cart = self.users[user_id]['cart']
        if not cart:
            return None

        for product_name in cart:
            if product_name not in self.products:
                return None

        reservations = self.users[user_id]['reservations']
        for product_name, quantity in cart.items():
            if reservations.get(product_name, 0) != quantity:
                return None

        price_snapshot = {}
        total_price = 0.0
        for product_name, quantity in cart.items():
            price = self.products[product_name]['price']
            price_snapshot[product_name] = price
            total_price += price * quantity

        with self.lock:
            order_id = f"SK{self.next_order_id:05d}"
            self.next_order_id += 1

        self.orders[order_id] = {
            'user_id': user_id,
            'products': [{'name': name, 'quantity': qty} for name, qty in cart.items()],
            'status': 'pending',
            'price_snapshot': price_snapshot
        }

        self.users[user_id]['cart'] = {}
        self.users[user_id]['reservations'] = {}

        return order_id

    def update_order_status(self, order_id, new_status):
        if order_id not in self.orders:
            return False

        current_status = self.orders[order_id]['status']

        if current_status == 'cancelled':
            return False

        if new_status not in self.order_status_sequence.get(current_status, []):
            return False

        if current_status == 'delivered' and new_status != 'cancelled':
            return False

        if new_status == 'cancelled':
            for product in self.orders[order_id]['products']:
                product_name = product['name']
                quantity = product['quantity']
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = self.orders[order_id]['price_snapshot'].get(product_name, 0.0)
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

        self.orders[order_id]['status'] = new_status
        return True

    def get_system_state(self):
        with self.lock:
            state = {
                'users': {k: v.copy() for k, v in self.users.items()},
                'products': self.products.copy(),
                'orders': {k: v.copy() for k, v in self.orders.items()}
            }
        return state

import threading

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.order_status_sequence = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }
        self.lock = threading.Lock()

    def create_user(self, user_id):
        if user_id in self.users:
            return False

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }
        return True

    def delete_user(self, user_id):
        if user_id not in self.users:
            return False
        user_data = self.users[user_id]
        reservations = user_data['reservations']
        for product_name, quantity in reservations.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
        del self.users[user_id]
        return True

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

        return True

    def delete_product(self, name):
        if name not in self.products:
            return False

        del self.products[name]
        return True

    def modify_cart(self, user_id, product_name, quantity, action):
        if user_id not in self.users:
            return False

        if action == 'add':
            if quantity <= 0:
                return False

            if product_name not in self.products:
                return False

            if quantity > self.products[product_name]['stock']:
                return False

            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] += quantity
            else:
                self.users[user_id]['reservations'][product_name] = quantity

            self.products[product_name]['stock'] -= quantity
            return True

            if product_name not in self.users[user_id]['cart'] or quantity <= 0:
                return False

                return False

                return True

                    del self.users[user_id]['reservations'][product_name]

            self.products[product_name]['stock'] += quantity
            return True

        return False

    def checkout(self, user_id):
        if user_id not in self.users:
            return None

        cart = self.users[user_id]['cart']
        if not cart:

                return None

            price_snapshot[product_name] = price
            total_price += price * quantity

            order_id = f"SK{self.next_order_id:05d}"

        }

                    if price > 0:

                            'price': price,
                            'stock': quantity
                        }

import threading

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.order_status_sequence = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }
        self.lock = threading.Lock()

    def create_user(self, user_id):
        if user_id in self.users:
            return False

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }
        return True

    def delete_user(self, user_id):
        if user_id not in self.users:
            return False
        user_data = self.users[user_id]
        reservations = user_data['reservations']
        for product_name, quantity in reservations.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
        del self.users[user_id]
        return True

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

        return True

    def delete_product(self, name):
        if name not in self.products:
            return False

        del self.products[name]
        return True

    def modify_cart(self, user_id, product_name, quantity, action):
        if user_id not in self.users:
            return False

        if action == 'add':
            if quantity <= 0:
                return False

            if product_name not in self.products:
                return False

            if quantity > self.products[product_name]['stock']:
                return False

            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] += quantity
            else:
                self.users[user_id]['reservations'][product_name] = quantity

            self.products[product_name]['stock'] -= quantity
            return True

        elif action == 'remove':
            if product_name not in self.users[user_id]['cart'] or quantity <= 0:
                return False

            if quantity > self.users[user_id]['cart'][product_name]:
                return False

            if product_name not in self.products:
                return False

            self.users[user_id]['cart'][product_name] -= quantity

            if self.users[user_id]['cart'][product_name] == 0:
                del self.users[user_id]['cart'][product_name]

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] -= quantity
                if self.users[user_id]['reservations'][product_name] == 0:
                    del self.users[user_id]['reservations'][product_name]

            self.products[product_name]['stock'] += quantity
            return True

        return False

    def checkout(self, user_id):
        if user_id not in self.users:
            return None

        cart = self.users[user_id]['cart']
        if not cart:
            return None

        for product_name in cart:
            if product_name not in self.products:
                return None

        reservations = self.users[user_id]['reservations']
        for product_name, quantity in cart.items():
            if reservations.get(product_name, 0) != quantity:
                return None

        price_snapshot = {}
        total_price = 0.0
        for product_name, quantity in cart.items():
            price = self.products[product_name]['price']
            price_snapshot[product_name] = price
            total_price += price * quantity

        with self.lock:
            order_id = f"SK{self.next_order_id:05d}"
            self.next_order_id += 1

        self.orders[order_id] = {
            'user_id': user_id,
            'products': [{'name': name, 'quantity': qty} for name, qty in cart.items()],
            'status': 'pending',
            'price_snapshot': price_snapshot
        }

        self.users[user_id]['cart'] = {}
        self.users[user_id]['reservations'] = {}

        return order_id

    def update_order_status(self, order_id, new_status):
        if order_id not in self.orders:
            return False

        current_status = self.orders[order_id]['status']

        if current_status == 'cancelled':
            return False

        if new_status not in self.order_status_sequence.get(current_status, []):
            return False

        if current_status == 'delivered' and new_status != 'cancelled':
            return False

        if new_status == 'cancelled':
            for product in self.orders[order_id]['products']:
                product_name = product['name']
                quantity = product['quantity']
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = self.orders[order_id]['price_snapshot'].get(product_name, 0.0)
                    if price > 0:
                        self.products[product_name] = {
                            'price': price,
                            'stock': quantity
                        }

        self.orders[order_id]['status'] = new_status
        return True

    def get_system_state(self):
        with self.lock:
            state = {
                'users': {k: v.copy() for k, v in self.users.items()},
                'products': self.products.copy(),
                'orders': {k: v.copy() for k, v in self.orders.items()}
            }
        return state

   - processing → completed | cancelled
   - completed → shipped | cancelled
   - shipped → delivered | cancelled
   - delivered → cancelled
   - cancelled → (no further transitions)
4. Price snapshots must be captured at time of order creation and remain immutable
5. Order IDs must follow the format "SK" followed by 5-digit number (e.g., SK00001)

import threading

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1
        self.order_status_sequence = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }
        self.lock = threading.Lock()

    def create_user(self, user_id):
        if user_id in self.users:
            return False

        self.users[user_id] = {
            'cart': {},
            'reservations': {}
        }
        return True

    def delete_user(self, user_id):
        if user_id not in self.users:
            return False
        user_data = self.users[user_id]
        reservations = user_data['reservations']
        for product_name, quantity in reservations.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
        del self.users[user_id]
        return True

    def add_product(self, name, price, stock):
        if not name or price < 0 or stock < 0:
            return False

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

        return True

    def delete_product(self, name):
        if name not in self.products:
            return False

        del self.products[name]
        return True

    def modify_cart(self, user_id, product_name, quantity, action):
        if user_id not in self.users:
            return False

        if action == 'add':
            if quantity <= 0:
                return False

            if product_name not in self.products:
                return False

            if quantity > self.products[product_name]['stock']:
                return False

            if product_name in self.users[user_id]['cart']:
                self.users[user_id]['cart'][product_name] += quantity
            else:
                self.users[user_id]['cart'][product_name] = quantity

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] += quantity
            else:
                self.users[user_id]['reservations'][product_name] = quantity

            self.products[product_name]['stock'] -= quantity
            return True

        elif action == 'remove':
            if product_name not in self.users[user_id]['cart'] or quantity <= 0:
                return False

            if quantity > self.users[user_id]['cart'][product_name]:
                return False

            if product_name not in self.products:
                return False

            self.users[user_id]['cart'][product_name] -= quantity

            if self.users[user_id]['cart'][product_name] == 0:
                del self.users[user_id]['cart'][product_name]

            if product_name in self.users[user_id]['reservations']:
                self.users[user_id]['reservations'][product_name] -= quantity
                if self.users[user_id]['reservations'][product_name] == 0:
                    del self.users[user_id]['reservations'][product_name]

            self.products[product_name]['stock'] += quantity
            return True

        return False

    def checkout(self, user_id):
        if user_id not in self.users:
            return None

        cart = self.users[user_id]['cart']
        if not cart:
            return None

        for product_name in cart:
            if product_name not in self.products:
                return None

        reservations = self.users[user_id]['reservations']
        for product_name in cart:
            if product_name not in reservations or reservations[product_name] != cart[product_name]:
                return None

        price_snapshot = {}
        total_price = 0.0
        for product_name, quantity in cart.items():
            price = self.products[product_name]['price']
            price_snapshot[product_name] = price
            total_price += price * quantity

        with self.lock:
            order_id = f"SK{self.next_order_id:05d}"
            self.next_order_id += 1

        self.orders[order_id] = {
            'user_id': user_id,
            'products': [{'name': name, 'quantity': qty} for name, qty in cart.items()],
            'status': 'pending',
            'price_snapshot': price_snapshot
        }

        self.users[user_id]['cart'] = {}
        self.users[user_id]['reservations'] = {}

        return order_id

    def update_order_status(self, order_id, new_status):
        if order_id not in self.orders:
            return False

        current_status = self.orders[order_id]['status']

        if current_status == 'cancelled':
            return False

        if new_status not in self.order_status_sequence.get(current_status, []):
            return False

        if current_status == 'delivered' and new_status != 'cancelled':
            return False

        if new_status == 'cancelled':
            for product in self.orders[order_id]['products']:
                product_name = product['name']
                quantity = product['quantity']
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = self.orders[order_id]['price_snapshot'].get(product_name, 0.0)
                    if price > 0:
                        self.products[product_name] = {
                            'price': price,
                            'stock': quantity
                        }

        self.orders[order_id]['status'] = new_status
        return True

    def get_system_state(self):
        with self.lock:
            state = {
                'users': {k: v.copy() for k, v in self.users.items()},
                'products': self.products.copy(),
                'orders': {k: v.copy() for k, v in self.orders.items()}
            }
        return state
