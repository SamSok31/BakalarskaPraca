Use Case: Manage E-Shop Backend System
Primary Actor: User (Administrator/Customer)
Goal: Manage users, products, carts, reservations, and orders in an e-shop backend system while ensuring correct handling of current available stock.

System Responsibilities:
- Manage user accounts, including creation and deletion.
- Maintain product catalog with attributes (name, price, stock).
- Handle cart operations (add/remove products) and reservations.
- Process checkout to create orders with atomicity.
- Update order statuses following strict transition rules.
- Ensure stock consistency across reservations, checkouts, and cancellations.
- Generate globally unique and sequential order IDs.
- Provide access to current system state (users, products, stock, carts, orders).

Preconditions:
- The e-shop backend system is initialized and operational.
- No prior state corruption exists (e.g., invalid stock quantities, orphaned reservations).

Postconditions:
- Users, products, carts, reservations, and orders are in a consistent state.
- Stock quantities reflect all successful operations (reservations, checkouts, cancellations).
- Order statuses adhere to defined transition rules.
- Order IDs are unique and sequential.

---

### Use Case: Create User
**Primary Actor:** Administrator
**Goal:** Add a new user to the system.

**System Responsibilities:**
- Validate uniqueness of user ID.
- Create an empty cart for the new user.

**Preconditions:**
- System is operational.

**Postconditions:**
- A new user with the specified ID exists.
- The user has an empty cart.

**Main Success Scenario:**
1. Administrator requests to create a user with a unique ID.
2. System validates the ID is not a duplicate.
3. System creates the user with the provided ID.
4. System initializes an empty cart for the user.

**Extensions:**
2a. User ID already exists → System ignores the request.

---

### Use Case: Delete User
**Primary Actor:** Administrator
**Goal:** Remove a user from the system.

**System Responsibilities:**
- Remove the user’s cart and cancel their reservations.
- Return reserved stock to available stock if the product exists.
- Preserve the user’s existing orders.

**Preconditions:**
- User exists in the system.

**Postconditions:**
- User, their cart, and reservations are removed.
- Reserved stock is returned to available stock (if product exists).
- User’s orders remain unchanged.

**Main Success Scenario:**
1. Administrator requests to delete a user.
2. System removes the user’s cart and cancels all reservations.
3. For each reservation:
   - If the product exists, system returns the reserved quantity to available stock.
   - If the product does not exist, system removes the reservation without stock adjustment.
4. System removes the user.

**Extensions:**
1a. User does not exist → System ignores the request.

---

### Use Case: Add/Update Product
**Primary Actor:** Administrator
**Goal:** Add a new product or update an existing product’s stock and price.

**System Responsibilities:**
- Validate product attributes (name, price, stock).
- Update stock and price if the product already exists.

**Preconditions:**
- System is operational.

**Postconditions:**
- Product exists in the system with updated attributes (name, price, stock).

**Main Success Scenario:**
1. Administrator requests to add/update a product with name, price, and stock.
2. System checks if the product already exists.
   - If it exists, system updates the stock (adds new stock) and price.
   - If it does not exist, system creates the product with the provided attributes.
3. System confirms the product is added/updated.

**Extensions:**
1a. Product name is empty or invalid → System ignores the request.
1b. Price or stock is negative → System ignores the request.

---

### Use Case: Delete Product
**Primary Actor:** Administrator
**Goal:** Remove a product from the current available stock system.

**System Responsibilities:**
- Remove the product from available stock.
- Preserve existing reservations and orders.

**Preconditions:**
- Product exists in the system.

**Postconditions:**
- Product is removed from available stock.
- Reservations and orders involving the product remain unchanged.

**Main Success Scenario:**
1. Administrator requests to delete a product.
2. System removes the product from available stock.
3. System confirms the product is deleted.

**Extensions:**
1a. Product does not exist → System ignores the request.

### Use Case: Modify Cart
**Primary Actor:** Customer
**Goal:** Add or remove products from the cart, creating or updating reservations.

**System Responsibilities:**
- Validate product availability and requested quantities.
- Update reservations and available stock.
- Handle edge cases (e.g., zero quantity, non-existent products).

**Preconditions:**
- User exists in the system.
- Cart exists for the user.

**Postconditions:**
- Cart reflects the requested changes.
- Reservations and available stock are updated accordingly.

**Main Success Scenario (Add Product):**
1. Customer requests to add a product with a specified quantity to their cart.
2. System checks if the product exists and has sufficient available stock.
3. System updates the reservation (or creates a new one) and deducts the quantity from available stock.
4. System confirms the product is added to the cart.

**Main Success Scenario (Remove Product):**
1. Customer requests to remove a product with a specified quantity from their cart.
2. System checks if the product exists in the cart and the requested quantity is valid.
3. System reduces or removes the reservation and returns the quantity to available stock (if product exists).
4. System confirms the product is removed from the cart.

**Extensions:**
1a. Product does not exist or quantity is zero → System ignores the request.
1b. Requested quantity exceeds available stock (add) → System ignores the request.
1c. Requested quantity exceeds reserved quantity (remove) → System ignores the request.
1d. Product no longer exists in stock (remove) → System removes the reservation without stock adjustment.

---

### Use Case: Checkout
**Primary Actor:** Customer
**Goal:** Convert the cart into an order.

**System Responsibilities:**
- Validate cart contents and product availability.
- Create an order with a snapshot of product prices.
- Clear the cart and reservations.
- Generate a unique and sequential order ID.

**Preconditions:**
- User exists in the system.
- Cart is not empty.

**Postconditions:**
- A new order with status "pending" is created.
- Cart and reservations are cleared.
- Order ID is generated in the format "SK00001" (sequential).

**Main Success Scenario:**
1. Customer requests to checkout their cart.
2. System validates that all reserved products exist in the stock system.
3. System calculates the total price using current product prices.
4. System creates a new order with status "pending" and stores a snapshot of product prices.
5. System generates a unique order ID in the format "SK00001" (sequential).
6. System clears the cart and reservations.
7. System confirms the order is created.

**Extensions:**
1a. Cart is empty → System ignores the request.
2a. Any reserved product does not exist in the stock system → System fails the checkout and applies no changes.

---

### Use Case: Update Order Status
**Primary Actor:** Administrator
**Goal:** Change the status of an order.

**System Responsibilities:**
- Validate status transitions.
- Handle stock adjustments for cancellations.
- Recreate products if necessary (for cancelled orders).

**Preconditions:**
- Order exists in the system.

**Postconditions:**
- Order status is updated according to transition rules.
- Stock is adjusted if the order is cancelled.

**Main Success Scenario:**
1. Administrator requests to update an order’s status.
2. System validates the requested status transition.
3. System updates the order status.
4. If the new status is "cancelled":
   - For each product in the order:
     - If the product exists, system increases available stock by the ordered quantity.
     - If the product does not exist, system recreates it with the price stored in the order.
5. System confirms the status update.

**Extensions:**
1a. Order does not exist → System ignores the request.
2a. Invalid status transition → System ignores the request.
3a. Status is "cancelled" and product no longer exists → System recreates the product with the order’s price.

---

**Primary Actor:** Administrator/Customer
**Goal:** Retrieve current system state (users, products, stock, carts, orders).

**System Responsibilities:**
- Provide read-only access to system state.

**Preconditions:**
- System is operational.

**Postconditions:**
- System state is returned to the actor.

**Main Success Scenario:**
1. Actor requests to view system state (users, products, stock, carts, or orders).
2. System retrieves and returns the requested state.

### Use Case: Manage E-Shop Backend System
Primary Actor: User (Administrator/Customer)
Goal: Manage users, products, carts, reservations, and orders in an e-shop backend system while ensuring correct handling of current available stock.

System Responsibilities:

- Maintain product catalog with attributes (name, price, stock).
- Handle cart operations (add/remove products) and reservations.
- Process checkout to create orders with atomicity (all-or-nothing).
- Update order statuses following strict transition rules: pending -> processing -> completed -> shipped -> delivered, where "cancelled" is a terminal state allowed from any status and further changes are ignored.
- Ensure stock consistency across reservations, checkouts, and cancellations, including recreation of products for cancelled orders when the product no longer exists.
- Generate globally unique and sequential order IDs that are never reused, even after order cancellation.
- Provide access to current system state (users, products, current available stock, carts, orders).

Preconditions:
- The e-shop backend system is initialized and operational.
- No prior state corruption exists (e.g., invalid stock quantities, orphaned reservations).

Postconditions:
- Users, products, carts, reservations, and orders are in a consistent state.
- Stock quantities reflect all successful operations (reservations, checkouts, cancellations).
- Order statuses adhere to defined transition rules.
- Order IDs are unique, sequential, and never reused.

    order = self.orders[order_id]
    current_status = order['status']

    valid_transitions = {
        'pending': ['processing'],
        'processing': ['completed'],
        'completed': ['shipped'],
        'shipped': ['delivered'],
        'delivered': ['cancelled'],
        'cancelled': []
    }

    # Check if transition is valid
    if new_status not in valid_transitions.get(current_status, []):
        return

    # Update order status
    order['status'] = new_status

    # Handle cancellation
    if new_status == 'cancelled':
        for product_name, quantity in order['items'].items():
            # Increase stock if product exists
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            # Recreate product with price from snapshot if it doesn't exist
            else:
                price = order['price_snapshot'].get(product_name, 0.0)
                self.products[product_name] = {

                    'stock': quantity

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        total_quantity = quantity
        if product_name in user['cart']:
            total_quantity += user['cart'][product_name]

        if product['stock'] < total_quantity:
            return

        user['cart'][product_name] = total_quantity
        product['stock'] -= total_quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing'],
            'processing': ['completed'],
            'completed': ['shipped'],
            'shipped': ['delivered'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        total_quantity = quantity
        if product_name in user['cart']:
            total_quantity += user['cart'][product_name]

        if product['stock'] < total_quantity:
            return

        if product_name in user['cart']:
            product['stock'] += user['cart'][product_name]

        user['cart'][product_name] = total_quantity
        product['stock'] -= total_quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing'],
            'processing': ['completed'],
            'completed': ['shipped'],
            'shipped': ['delivered'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        total_quantity = quantity
        if product_name in user['cart']:
            total_quantity += user['cart'][product_name]

        if product['stock'] < total_quantity:
            return

        if product_name in user['cart']:
            product['stock'] += user['cart'][product_name]

        user['cart'][product_name] = total_quantity
        product['stock'] -= total_quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing'],
            'processing': ['completed'],
            'completed': ['shipped'],
            'shipped': ['delivered'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        if product['stock'] < quantity:
            return

        if product_name in user['cart']:
            user['cart'][product_name] += quantity
        else:
            user['cart'][product_name] = quantity

        product['stock'] -= quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing'],
            'processing': ['completed'],
            'completed': ['shipped'],
            'shipped': ['delivered'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        if product['stock'] < quantity:
            return

        if product_name in user['cart']:
            user['cart'][product_name] += quantity
        else:
            user['cart'][product_name] = quantity

        product['stock'] -= quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing'],
            'processing': ['completed'],
            'completed': ['shipped'],
            'shipped': ['delivered'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0 or stock < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        if product['stock'] < quantity:
            return

        if product_name in user['cart']:
            user['cart'][product_name] += quantity
        else:
            user['cart'][product_name] = quantity

        product['stock'] -= quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():

                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

class EShopSystem:
    def __init__(self):
        self.users = {}
        self.products = {}
        self.orders = {}
        self.next_order_id = 1

    def create_user(self, user_id):
        if user_id not in self.users:
            self.users[user_id] = {'cart': {}}

    def delete_user(self, user_id: str) -> None:
        if user_id not in self.users:
            return

        user_cart = self.users[user_id]['cart'].copy()
        for product_name, quantity in user_cart.items():
            if product_name in self.products:
                self.products[product_name]['stock'] += quantity
            self.users[user_id]['cart'].pop(product_name, None)

        del self.users[user_id]

    def add_or_update_product(self, name, price, stock):
        if not isinstance(name, str) or not name.strip() or price < 0 or stock < 0:
            return

        if name in self.products:
            self.products[name]['price'] = price
            self.products[name]['stock'] += stock
        else:
            self.products[name] = {
                'price': price,
                'stock': stock
            }

    def delete_product(self, name: str) -> None:
        if name in self.products:
            del self.products[name]

    def add_to_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.products or quantity <= 0:
            return

        product = self.products[product_name]
        user = self.users[user_id]

        if product['stock'] < quantity:
            return

        if product_name in user['cart']:
            user['cart'][product_name] += quantity
        else:
            user['cart'][product_name] = quantity

        product['stock'] -= quantity

    def remove_from_cart(self, user_id: str, product_name: str, quantity: int) -> None:
        if user_id not in self.users or product_name not in self.users[user_id]['cart'] or quantity <= 0:
            return

        if product_name not in self.products:
            del self.users[user_id]['cart'][product_name]
            return

        reserved_quantity = self.users[user_id]['cart'][product_name]

        if quantity > reserved_quantity:
            return

        if quantity >= reserved_quantity:
            del self.users[user_id]['cart'][product_name]
            self.products[product_name]['stock'] += reserved_quantity
        else:
            self.users[user_id]['cart'][product_name] -= quantity
            self.products[product_name]['stock'] += quantity

    def checkout(self, user_id):
        if user_id not in self.users or not self.users[user_id]['cart']:
            return None

        cart = self.users[user_id]['cart']
        for product_name in cart:
            if product_name not in self.products or self.products[product_name]['price'] < 0:
                return None

        total_price = 0.0
        price_snapshot = {}
        for product_name, quantity in cart.items():
            price_snapshot[product_name] = self.products[product_name]['price']
            total_price += quantity * self.products[product_name]['price']

        order_id = f"SK{self.next_order_id:05d}"
        self.orders[order_id] = {
            'status': 'pending',
            'items': cart.copy(),
            'price_snapshot': price_snapshot,
            'user_id': user_id
        }
        self.users[user_id]['cart'].clear()
        self.next_order_id += 1

        return order_id

    def update_order_status(self, order_id: str, new_status: str) -> None:
        if order_id not in self.orders:
            return

        order = self.orders[order_id]
        current_status = order['status']

        if current_status == 'cancelled':
            return

        valid_transitions = {
            'pending': ['processing', 'cancelled'],
            'processing': ['completed', 'cancelled'],
            'completed': ['shipped', 'cancelled'],
            'shipped': ['delivered', 'cancelled'],
            'delivered': ['cancelled'],
            'cancelled': []
        }

        if new_status not in valid_transitions.get(current_status, []):
            return

        order['status'] = new_status

        if new_status == 'cancelled':
            for product_name, quantity in order['items'].items():
                if product_name in self.products:
                    self.products[product_name]['stock'] += quantity
                else:
                    price = order['price_snapshot'].get(product_name, 0.0)
                    if price < 0:
                        price = 0.0
                    self.products[product_name] = {
                        'price': price,
                        'stock': quantity
                    }

    def get_system_state(self):
        return {
            "users": {k: v.copy() for k, v in self.users.items()},
            "products": {k: v.copy() for k, v in self.products.items()},
            "orders": {k: v.copy() for k, v in self.orders.items()}
        }

def main():
